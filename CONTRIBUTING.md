# Contributing to valence

Thank you for your interest in contributing to Lineage Foundation **valence** (L2 node).

## How to contribute

1. **Open an issue** – Bugs, features, or questions in this repository.
2. **Fork and clone** – Fork and clone locally.
3. **Create a branch** – e.g. `feat/...`, `fix/...`.
4. **Make changes** – Follow [.editorconfig](.editorconfig); run `cargo fmt` and `cargo clippy` as appropriate.
5. **Run tests** – `cargo test` (services like Redis/MongoDB may be required for integration tests).
6. **Submit a PR** – Against `main`.

## Code style

- Rust: 4-space indent per [.editorconfig](.editorconfig).
- [Conventional Commits](https://www.conventionalcommits.org/) for messages.
